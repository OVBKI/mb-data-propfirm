# Fleetly — Signal

Identité visuelle sur-mesure pour **Fleetly**, SaaS de gestion de flotte de transport (B2B international).
Ton : moderne, fiable, « tech logistique ». Le bleu inspire la confiance et le sérieux ;
l'accent cyan évoque le suivi GPS / le temps réel / le mouvement.
